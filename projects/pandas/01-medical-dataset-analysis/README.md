# Medical Dataset Analysis

## Project Overview

An introductory Exploratory Data Analysis (EDA) project using Python and Pandas to explore a small synthetic medical-label dataset.

The project focuses on understanding dataset structure, identifying data-quality issues, and summarizing medical-label distributions.

## Dataset Information

- Dataset type: Synthetic medical-label data
- Records: 9
- Columns: 4
- Includes a missing Pneumonia label and a repeated image identifier.

This is an educational dataset, not real patient data or clinical research.

## Objectives

- Create and explore a Pandas DataFrame.
- Inspect dataset dimensions and structure.
- Identify missing values.
- Detect duplicate records and identifiers.
- Select and filter columns.
- Count medical labels.
- Visualize label distributions.
- Summarize findings.

## Pandas Concepts Practiced

- DataFrame creation
- `shape`, `head()`, and `info()`
- `isnull()` and missing-value analysis
- `duplicated()`
- Column selection
- `value_counts()`
- Basic data visualization
- CSV export
